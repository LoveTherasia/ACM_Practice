# 题型做法库：从代码注释与书写过程提炼

`汇总题单.md` 只是作者笔记的一部分。本文件补充**另一半证据**：语料 233 个文件里的 1294 条中文注释、467 条被注释掉的调试行、每日打卡的题目标签、以及 solve() 的书写顺序本身。每条做法都标注了出处文件，可直接打开对照。

## 元策略（跨题型的思维手法，从注释中直接观察到）

1. **条件拆分。** 把复合约束拆成两个单向条件分别满足：`|a[i] - a[i-1]| <= 1` 拆成 `a[i] <= a[i-1]+1` 和 `a[i-1] <= a[i]+1`，"先从前往后满足第一个条件，然后再从后往前满足第二个条件"（`AtCoder\abc_443\D.cpp`，注释 45 行起）。
2. **代数恒等变形，寻找"很熟悉的式子"。** `2220\C.cpp` 完整保留推导：线段总数 `n(m+1)+m(n+1) = 2mn+m+n` → "发现左边是一个很熟悉的式子，两边同时乘 2 并 +1" → `(2m+1)(2n+1) = 2(p+2q)+1`，于是答案 = 线段总数的**奇数因数对**。随后再回补遗漏约束（"1 7 并不是合理的解……所以这里应该还有其他的约束"）推得 `|2m-2n| <= 2p`。**套路：化不熟为熟悉 + 样例反推约束**。
3. **仿写熟悉的模板解决变体。** 三进制异或线性基："这里尽可能全程仿造二进制的异或线性基的写法……如果这一位上是 2，那么我们要将其变为 1"（`algorithm\线性基\hdu-1199-1005-三进制异或线性基.cpp`）。新数据结构变体 = 找最接近的已知模板 + 逐条改写差异。
4. **负下标加偏移量。** `prei - prej` 可为负时，"区间为 -n 到 n，所以我们要以 n 为偏移量……加上偏移量 n + 1 是为了防止跑到 0 的情况"（`AtCoder\abc_441\E.cpp`）。
5. **正确性证明内嵌**。`ICPC\2024chengdu\II.cpp` 在注释里逐个排除反例："有没有一种情况是修改 p 位置后 p-1 和 p 原本都不是断点后面又变成了断点？很明显不存在这种情况，因为……""很明显存在这种情况，但是这样子计算会有问题"——**写完主体后，对边界组合逐个自问自答**。
6. **手推小例 → 归纳结论 → 倒推算法。** `AtCoder\arc_218\B.cpp` 注释区是 9 行手写对局（"3 1 4 1 5 9 2 后手必胜……"），归纳出结论一/结论二，再"从最大值出发往前推"设计出 set 存大小 + map 存数量的算法。
7. **贡献扫描（+1/-1 平衡）。** 维护每个元素贡献区间，出现则加、离开则减："向线段树添加贡献，对区间 [nx[i],la[i]] 加一""如果当前的值已经出现过，先删除旧位置的贡献"（`nowcoder\108307\F.cpp`）。
8. **后缀最大值连同其位置一起存。** "bac 的后缀最大值数组""bac 的后缀最大值位置数组"（`AtCoder\abc_438\D.cpp`）——取最值的同时需要知道"在哪取的"就开一对数组。

## 题型做法条目

### 位运算构造（逐位状态机）
`codeforces\443\A.cpp`：对每个二进制位分类终态——"必定变成 0 / 必定变成 1 / 不确定保持 / 不确定取反"，编码成 1/2/3/4 四个状态，然后逐种运算推导状态转移（"如果这个位跟 1 进行了或运算，那么就是必定变成 1"），最后按状态输出对应操作。**套路：位无关性 + 每位小状态机。**

### 构造题（拓扑式增量）
`CCPC\2024_Guangzhou\C.cpp`：把"只能确定的东西"先入队——"初始化队列：找到所有目标颜色种类数为 1 的节点"，处理一个就更新邻居计数，"如果邻居节点的目标颜色种类数变为 1，加入队列"。结尾还写验证循环"验证所有边是否都达到了目标颜色"。**套路：找自由度唯一的元素先确定，像拓扑排序一样扩展，最后自验。**

### 硬实现题（工程分解）
`nowcoder\109298\H.cpp`（38 条注释）：把"区间翻转 O(1) + 区间比较"拆成四层工程：差分数组（翻转只动两个端点）→ 差分值分块 → 块内预处理 `1<<16` 全部 Info → 跨块传递奇偶翻转标志（"前面块可能会留下奇数个 1……需要记录前面所有 1 的个数是奇数还是偶数"）。**套路：每个瓶颈操作先降一档复杂度，块间只传最小状态。**

### 线段树合并 / 动态开点
`nowcoder\2026暑期多校第九场\D.cpp`：BFS 建树 → 离散化时间 T → 每人按 T 分组 → 叶子插入动态开点线段树 → 自底向上合并，"当前节点该 T 已经碰撞，那么两边的人都消失"。每个数组都有语义注释（`//左右节点编号`、`//存储幸存者编号`）。

### 树上启发式合并
`CF600E.cpp` / `cf600e_source.cpp`：四个预处理数组（`siz`、`son` 重儿子、`dep`、`fa`）+ 两遍 DFS——先遍历轻儿子并**回滚**其贡献，再遍历重儿子保留，最后把当前子树逐点累加进全局 `cnt[]`（`//当前颜色出现次数最大值`、`//当前颜色出现最大值的颜色编号之和`）。

### 轮廓线 / 逐行状压 DP
`AtCoder\abc_424\D.cpp`：状态是"当前行的某种填法"，转移枚举上一行状态并检查兼容；调试注释保留了完整的中间量打印（当前行修改个数、是否符合、`dp[i][j]`）——**逐行 DP 的验证方式是把行号、状态、合法性全打印出来**。

### 二分答案的复合形态
`AtCoder\abc_440\D.cpp`：两次二分——第一次"二分查找最大的 a[i] 保证 a[i] < x"把"找第几个不在列表上的数字"转化成已知序，第二次在补齐后的数组里定位。调试注释打印每次二分的 `l` 和"一次二分结果"。**套路：把不规则的计数问题先用一次二分化成规则问题。**

### 分组余数 DP
`AtCoder\abc_419\E.cpp`：数组分组（`//将数组分为 1-l 组`），组内枚举元素和余数，转移写 `dp[i][(j + delta) % m]`，"计算将该组中索引为 j 的元素变为对 m 求余等于 (i + j) % m 的元素需要的操作数"。

### 计算几何（极角排序）
`AtCoder\abc_442\E.cpp`：点积/叉积注释（`//向量点积`、`//叉积小于零说明是在逆时针方向`），"将象限分为上下两部分来排序"，共线用"叉积为零且点乘大于零表示共向"消歧。

### 线段树维护复合量
`codeforces\1072_Div2\E.cpp`：`push_up` 里两个子树信息**不能合并**时存 -1（"如果 num1 == num2 && num1 != -1 才传递"），配套懒标记整段覆盖。**套路：当区间信息可能"无统一答案"时，用哨兵值表示不可合并。**

## 做法记录的三个载体

1. **模板文件名即做法**：`一些板子集合\一些trick\` 下的文件名直接命名 trick（`logtrick加速寻找gcd个数.cpp`、`st表维护左端点在该范围内的右端点最小值.cpp`），板子目录全部文件都按"来源-算法"命名。找已知套路时**先扫文件名**。
2. **每日打卡标题 = 题型 + 做法**：`nowcoder\每日打卡\总结清单.md` 里每天的标题就是标签（"异或路径，打表找规律"、"组合数计算，预处理阶乘计算组合数"、"巴什博弈模板"）。
3. **代码注释类型学**（按出现频率）：
   - **数组语义注释**（最多）：每个不显然的全局数组上方一行——`//记录每个节点的重儿子节点`（CF600E）、`//Ci - Bi 的后缀和数组`（abc_438D）。
   - **状态定义注释**：DP 表上方——`//表示搜到第 i 位，前一位数字是 j 的方案数`（SCOI2009.cpp）。
   - **推导注释**：多行数学推导链（2220C、443A）。
   - **证明注释**：自问自答排除边界（chengdu II）。
   - **步骤注释**：按执行顺序给 solve() 分段（Guangzhou C 的编号步骤、多校九 D 的流程注释）。

这些注释类型是**被接受的解释性注释**（`SKILL.md` 第 5 步的例外条款），生成复杂题解时可以按对应类型加注释。
